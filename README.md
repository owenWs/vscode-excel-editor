# XLSM Editor - VS Code 扩展

[![Version](https://img.shields.io/badge/version-0.2.0-blue.svg)]()
[![License](https://img.shields.io/badge/license-MIT-green.svg)]()

在 Visual Studio Code 中直接查看和编辑 Excel 文件（.xlsm、.xlsx、.xls），完整保留 VBA 宏不丢失。

## ✨ 主要特性

### 核心功能
- 📊 **Excel 文件支持**：支持 .xlsm（带宏）、.xlsx、.xls 格式
- 🔒 **VBA 宏保护**：完整保留 VBA 宏，编辑保存后不会丢失
- ✏️ **单元格编辑**：支持值和公式的编辑
- 📑 **多工作表管理**：支持切换、新增、复制工作表
- 🎯 **类 Excel 体验**：熟悉的表格界面和键盘导航

### v0.2.0 新增功能
- ✨ **复制行**：将选中行复制到表格末尾，支持批量复制
- ✨ **复制列**：将选中列复制到表格末尾，支持批量复制
- ✨ **复制工作表**：一键复制整个工作表（包含所有数据、格式、公式）

## 📦 安装

### 方法一：从 VSIX 安装
1. 下载 `vscode-xlsm-editor-0.2.0.vsix`
2. 在 VS Code 中按 `Ctrl+Shift+P` (Mac: `Cmd+Shift+P`)
3. 输入 "Extensions: Install from VSIX..."
4. 选择下载的 .vsix 文件

### 方法二：命令行安装
```bash
code --install-extension vscode-xlsm-editor-0.2.0.vsix
```

## 🚀 使用方法

### 打开文件
在 VS Code 中直接打开 .xlsm、.xlsx 或 .xls 文件，插件会自动激活。

### 基本操作

#### 1. 单元格编辑
- **单击**选中单元格
- **双击**或按 `Enter`/`F2` 开始编辑
- **方向键**在单元格间导航
- **Tab** 移动到右侧单元格
- **Delete/Backspace** 清空单元格内容

#### 2. 公式栏编辑
- 顶部公式栏显示当前单元格的内容
- 可以在公式栏中编辑公式或值
- 按 `Enter` 提交，`Esc` 取消

#### 3. 工作表管理
- **切换工作表**：点击底部的 Sheet 标签页
- **新增工作表**：点击工具栏的"＋ 工作表"按钮
- **复制工作表**：点击工具栏的"复制工作表"按钮

#### 4. 插入行列
- **插入空行**：在"插入行"输入框输入数量，点击"＋ 行"按钮
- **插入空列**：在"插入列"输入框输入数量，点击"＋ 列"按钮

#### 5. 复制行列（新功能 🆕）
- **复制行**：
  1. 选中要复制的行中的任意单元格
  2. 在"复制选中行"输入框输入复制次数（默认 1）
  3. 点击"复制行"按钮
  4. 该行将被复制到表格末尾

- **复制列**：
  1. 选中要复制的列中的任意单元格
  2. 在"复制选中列"输入框输入复制次数（默认 1）
  3. 点击"复制列"按钮
  4. 该列将被复制到表格末尾

#### 6. 保存文件
- 按 `Ctrl+S` (Mac: `Cmd+S`) 保存
- 文件修改后标题栏会显示 `●` 标记

## ⚙️ 设置

在 VS Code 设置中可配置以下选项：

```json
{
  // GitHub 仓库地址，用于检查更新（格式：owner/repo）
  "xlsmEditor.githubRepo": "shun-wang/vscode-xlsm-editor",

  // 启动时自动检查更新
  "xlsmEditor.autoCheckUpdates": true
}
```

## 📝 技术细节

### 支持的功能
✅ 单元格值编辑
✅ 公式编辑和显示
✅ 多工作表切换
✅ 新增工作表
✅ 复制工作表（完整复制）
✅ 插入空行/列
✅ 复制指定行/列
✅ VBA 宏完整保留
✅ 文档修改状态追踪
✅ Ctrl+S 保存

### 暂不支持
❌ 单元格样式（颜色、字体、边框等）
❌ 删除行/列/工作表
❌ 合并单元格
❌ 图表和图片
❌ 数据验证和条件格式
❌ Undo/Redo（框架已就绪，待实现）

### 技术栈
- **语言**: TypeScript
- **核心库**: [xlsx.js](https://sheetjs.com/) (v0.18.5)
- **构建工具**: esbuild
- **VS Code API**: Custom Editor API

## 🐛 已知问题

1. 大文件（>10MB）可能加载较慢
2. 复杂公式可能显示为计算后的值
3. 不支持外部链接和动态数据源
